## 1. 项目定位

- 仓库：`github.com/mlke086/security-agent`（GitHub）
- 部署路径：`/home/app/security-agent`（centos10，192.168.80.101）
- 语言栈：Python 3.12（FastAPI / LangGraph / Elasticsearch / Redis / asyncpg）+ Go 1.24（Agent）+ React 18（前端）

## 4. 功能清单（按模块）

### 4.1 认证与 RBAC
- 登录（JWT）/ 用户管理（admin/analyst/viewer/responder 角色）
- 默认账号：`admin / admin123`（centos10 .env 的 DEFAULT_ADMIN_PASSWORD）

### 4.2 主机纳管（基础）
- Agent 注册（enroll token）、主机列表/详情/分组、在线离线心跳判定（mark_offline_expired）
- Agent 升级：`POST /agents/{id}/upgrade`（版本一致返回 already_current；离线下发置 offline；完整升级 0.2.1→0.4.0 已 E2E 验证 confirmed）

### 4.3 需求① 性能监控
- Go Agent `resource.Sample()`：cpu/mem/disk/net(kbps 差分)/load1，`metrics.Reporter` 每 15s 上报 `host_metrics`（WS fire-and-forget，断线丢弃）
- 服务端 `metrics_store.py`：ES `secagent-hostmetrics` 索引（显式 float mapping）
- `GET /agents/{id}/metrics?range=1h|24h|7d`（7d 走 date_histogram 降采样）+ `GET /agents/{id}/metrics/latest`
- 清扫：scheduler 每 6h 按 `metrics_retention_days`（默认 30）清理
- 前端 HostPerfDrawer：1h/24h/7d 折线图 + 最新快照卡片

### 4.4 需求② 内网资产扫描（agentless）
- 独立服务 asset-scan :8004 + 独立 Redis Stream `assetscan:queue:tasks`（TaskWorker 参数化）
- 扫描引擎：`scanner/version.py`（dpkg 版本比较，与 agent matcher 一致）、`runner.py`（子进程编排：超时/取消/限流）、`discovery.py`（ping/nmap 存活发现）、`fingerprint.py`（nmap -sV 服务指纹）、`vuln_match.py`（CVE 规则匹配 + nuclei -t 模板扫描）、`brute.py`（弱口令占位）
- LangGraph 子图 `subgraphs/asset_scan/`：parse→discover→fingerprint→match_vulns→llm_analysis→generate_report
- API 9 端点（创建/列表/详情/取消/删除/SSE 流/资产/漏洞/报告导出），RBAC admin/analyst
- ES 索引：`assetscan-tasks` / `assetscan-assets` / `assetscan-vulns` / `assetscan-reports`
- 前端 AssetScanPage：任务表单（IP/CIDR）+ 六态任务列表 + SSE 进度 + 资产/漏洞表格 + 报告

### 4.5 需求③ 漏洞清单（主机维度重构）
- `GET /vulnscan/results`：漏洞列表（57 条现存数据），`VulnFilter.agent_id` 过滤
- `GET /vulnscan/host-vuln-summary`：按主机聚合（ES terms agg + PG JOIN + 30s 缓存），返回 severity_counts/total/last_scan_at
- 前端 VulnListPage 双视图：按主机清单（漏洞 Tag/钻取）+ 按漏洞列表

### 4.6 对话 / AI 分析（ai 服务）
- 对话三分类、扫描意图识别、AI 漏洞分析（severity 判定/修复建议）、search-agent（Serper/Tavily）

### 4.7 事件 / 告警 / 队列
- 事件提交（`POST /api/v1/events`）、WS 事件流、任务监控、队列状态

## 8. 已知问题 / 遗留项

1. 应用服务无开机自启（建议补 systemd 单元）
2. 无活跃 Agent 上报（upg-e2e-v2 是历史心跳残留；性能监控无新数据）
3. `/opt/secagent/agent` + `secagent.service`（连 192.168.80.1 旧地址）仍在运行，与项目 Agent 无关，`systemctl restart secagent` 会重启它（升级 E2E 已踩坑）
4. `.env` 的 `API_SECRET_KEY` 为 dev 值（`dev-test-secret-key-change-in-prod!`），生产需更换
5. `e2e_*.sh` 测试脚本残留于项目根目录（待清理，见 RULES.md 临时文件清理）
6. graphrag 依赖（sentence-transformers/faiss 等）未全装，知识图谱功能可能降级
7. ES `vulnscan-hosts` 索引为 mirror（PG 主存储），非关键
