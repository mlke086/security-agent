# 项目全流程测试文档 V10（2026-07-31）

> **范围**：覆盖全项目 10 条业务链路 × 98 个 API endpoint × RBAC 4 角色的端到端测试方案。
> **精细度**：每条链路的每个步骤 → 输入/输出/副作用/失败模式 → 可执行测试用例。
> **基于**：2026-07-28 E2E 实测报告 + 当前 staged 工作树新增功能（nuclei 版本控制、模板同步、web search fallback、batch-delete、ES trace 修复）。
>
> **测试环境要求**：
> - 后端：`uvicorn` 0.0.0.0:8000
> - 数据库：PG 192.168.80.101:5432 + ES 192.168.80.101:9200 + Redis 192.168.80.101:6379 + Nacos 192.168.80.101:8848
> - Agent：至少 1 台 Linux agent 在线（Rocky001: v0.2.0+）
> - 认证：4 角色 token（admin / analyst / responder / viewer）

---
